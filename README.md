# fx-lights

Подсветка корпуса Alienware Aurora ACT1250 без Alienware Command Center: у каждой программы и игры свой цвет и режим.

Контроллер подсветки: AW-ELC, USB `187C:0550`. Проверено на прошивке 1.1.12 под Windows 11. На других моделях с этим контроллером может работать, но нумерация светодиодов там может отличаться (список `LEDS` в `aw_elc.py`).

## Что умеет

- Режимы: цвет, дыхание, пульс, перелив двух цветов, спектр, волна.
- Подсветка следует за активным окном и остаётся при Alt-Tab, пока программа из списка не закроется.
- Игры из Steam, Epic и GOG добавляются сами каждые 5 минут. Остальные программы добавляются в окне настроек.
- Значок в трее показывает текущий цвет: клик открывает настройки, правый клик даёт меню.
- После пробуждения из сна цвет отправляется заново.

## Запуск

Нужен Python 3.10 или новее с Tkinter. Сторонние пакеты, драйверы и права администратора не нужны. Command Center лучше удалить или закрыть, иначе он будет перебивать цвета.

```bash
pythonw fx_watch.pyw
```

Настройки открываются кликом по значку в трее или отдельно:

```bash
pythonw fx_ui.pyw
```

Для автозапуска положите в папку `shell:startup` ярлык на `pythonw fx_watch.pyw`.

Настройки хранятся в `fx-lights.json` рядом со скриптами, журнал в `fx-lights.log`. Оба файла не попадают в репозиторий.

## Файлы

| Файл | Назначение |
|---|---|
| `aw_elc.py` | Работа с контроллером через `hid.dll`, общие функции |
| `fx_watch.pyw` | Фоновая часть: следит за активным окном и меняет подсветку |
| `fx_tray.py` | Значок в трее |
| `fx_ui.pyw` | Окно настроек |
| `fx_games.py` | Поиск установленных игр |
| `import_awcc.py` | Разовый перенос цветов и игр из Command Center, запускать до его удаления |

Управление контроллером из командной строки:

```bash
python aw_elc.py status
```

```bash
python aw_elc.py play wave
```
